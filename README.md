# Openquote

**A domain-neutral engine for ongoing records.**

Openquote models the work of keeping a continuing relationship with the people you serve: subjects, cases that stay open over time, sessions, and schedules — plus editable code tables and aggregation over them. It knows nothing about any particular field; domain knowledge lives in the applications and packs built on top of it.

> Status: early development. Nothing is released yet.
